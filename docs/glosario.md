# Glosario

[Inicio](../README.md) · [Siguiente recurso](fuentes.md)

| Término | Significado |
|---|---|
| Alias | Referencias diferentes al mismo objeto |
| Arista | Relación entre vértices |
| BST | Árbol binario con regla de búsqueda por subárbol |
| Caso base | Caso que termina una reducción recursiva |
| Colisión | Claves diferentes que seleccionan la misma cubeta |
| Componente | Grupo conectado de un grafo no dirigido |
| Cubeta | Colección o posición seleccionada por hash |
| Deque | Colección con operaciones en ambos extremos |
| DFS | Búsqueda o recorrido en profundidad |
| BFS | Búsqueda o recorrido en amplitud |
| Encadenamiento | Resolución de colisiones por colección de cubeta |
| Estabilidad | Conservación del orden relativo de claves iguales |
| Factor de carga | Cociente elementos/cubetas |
| FIFO | Primero agregado, primero retirado |
| Hash | Transformación de clave para seleccionar ubicación |
| Invariante | Propiedad que se mantiene en puntos definidos |
| LIFO | Último agregado, primero retirado |
| Lista generalizada | Elementos que pueden ser átomos o sublistas |
| Memoización | Conservación de resultados de subproblemas |
| Nodo | Objeto con datos y enlaces |
| Precondición | Condición requerida antes de operar |
| Referencia | Valor que permite acceder a un objeto |
| TAD | Tipo abstracto definido por operaciones y reglas |
| Vértice | Elemento de un grafo |
