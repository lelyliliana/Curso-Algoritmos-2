# Fuentes de consulta

[Inicio](../README.md) · [Siguiente recurso](cierre.md)

Consulta documentación oficial y referencias académicas para ampliar conceptos. Los ejemplos del repositorio son implementaciones propias, con contratos y decisiones visibles.

- [Dev.java:aprender Java](https://dev.java/learn/): lenguaje, objetos y colecciones.
- [Documentación Java 21](https://docs.oracle.com/en/java/javase/21/docs/api/): contratos de métodos.
- [ArrayDeque](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/ArrayDeque.html) y [Deque](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Deque.html): pilas y colas.
- [HashMap](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/HashMap.html), [TreeMap](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/TreeMap.html) y [TreeSet](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/TreeSet.html): búsqueda y orden.
- [Princeton Algorithms](https://algs4.cs.princeton.edu/home/): análisis, estructuras, ordenamiento y grafos.
- [Merge sort](https://algs4.cs.princeton.edu/22 mergesort/) y [quick sort](https://algs4.cs.princeton.edu/23 quicksort/): partición, mezcla y análisis.
- [Tablas hash](https://algs4.cs.princeton.edu/34 hash/): funciones, colisiones y carga.
- [Grafos no dirigidos](https://algs4.cs.princeton.edu/41 graph/): representaciones, DFS, BFS y conectividad.
- [Temurin](https://adoptium.net/temurin/releases/?version=21): JDK 21 para distintos sistemas.

Una referencia no demuestra automáticamente que una implementación sea correcta. Comprueba que las precondiciones y el análisis corresponden a la versión concreta del algoritmo que utilizas.
