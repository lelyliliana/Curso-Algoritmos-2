# Unidad 3. Conceptualización de recursividad, árboles y grafos

[Inicio](../README.md) · [Mapa de temas](../docs/mapa-de-contenidos.md)

## Propósito

Resolver problemas recursivos y representar árboles y grafos con recorridos terminantes y verificables.

## Prueba inicial de comprensión

¿Qué necesita una recursión para terminar? ¿Todo árbol binario es de búsqueda? ¿Cómo evitarías repetir visitas en un grafo con ciclos?

Conserva tus respuestas y revísalas al finalizar. Si necesitas repasar Java, usa la [guía de repaso](../docs/repaso-java.md).
